# Project_DTDM

## 📌 Giới thiệu đề tài
**Triển khai hệ thống quản lý học tập Moodle trên Ubuntu Server bằng VirtualBox và công bố dịch vụ qua Cloudflare Tunnel.**

Đây là dự án thực hành nhóm thuộc học phần Điện toán đám mây, tập trung vào việc triển khai, cấu hình và vận hành hệ thống quản lý học tập Moodle trên môi trường máy chủ ảo.

## 🛠️ Công nghệ sử dụng
- VirtualBox
- Ubuntu Server
- Apache Web Server
- PHP
- MySQL
- Moodle LMS
- SSH / OpenSSH
- NAT và Port Forwarding
- Cloudflare Tunnel
- Bash Script

## 🚀 Chức năng đã triển khai
- Cài đặt và cấu hình Moodle trên Ubuntu Server.
- Tạo và quản lý tài khoản Admin, Teacher, Student.
- Tạo khóa học và phân quyền người dùng.
- Phân lịch giảng dạy bằng Calendar.
- Giáo viên đăng bài giảng và giao bài tập.
- Sinh viên xem tài liệu và nộp bài.
- Giáo viên chấm điểm và nhận xét.
- Công bố Moodle ra Internet bằng Cloudflare Tunnel.
- Quản trị máy chủ Ubuntu thông qua SSH.

## 📚 Kiến thức và kinh nghiệm đạt được
- Triển khai và quản trị máy chủ Linux.
- Sử dụng công nghệ ảo hóa VirtualBox.
- Cấu hình môi trường LAMP.
- Quản trị hệ thống từ xa bằng SSH.
- Hiểu cơ chế NAT, Port Forwarding và Cloudflare Tunnel.
- Triển khai và kiểm thử hệ thống LMS.
- Xử lý sự cố trong quá trình triển khai ứng dụng web.
